# Data

Raw input data is **not** redistributed in this repository. To reproduce the analysis, download:

| Dataset | Used for | Source |
|---|---|---|
| `TRIPSgeo_mun.gpkg`, `TRIPSgeo_freg.gpkg` | Trips by mode (IMOB 2018 survey, INE), aggregated to 18 municipalities and 118 parishes; boundaries based on CAOP 2022 (DGT) | MQAT course repository (GPL-3.0): https://github.com/U-Shift/MQAT/tree/main/geo |
| `BGRI21_LISBOA.gpkg` | Census 2021 statistical blocks (population, buildings) | INE Census 2021: https://mapas.ine.pt/download/index2021.phtml (course-provided extract for Lisbon) |
| OpenStreetMap (XYZ tiles) | Basemap | © OpenStreetMap contributors, https://www.openstreetmap.org/copyright |

Place the files in this `data/` folder (they are git-ignored).
